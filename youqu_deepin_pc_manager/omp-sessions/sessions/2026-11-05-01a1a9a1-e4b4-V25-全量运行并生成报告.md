\## 逐项判定方式

| 修复 | 硬编码版本分支 | 正确判定条件 | V20 上行为 |
|---|---|---|---|
| `--break-system-packages` | ✗ | `python3 -m pip --version` ≥ 23，或直接“带 flag 试一次，失败回退” | pip 20.3.4 不认识该参数 → 走到回退分支（现有代码已有回退，但回退分支缺 `--ignore-installed`） |
| `--ignore-installed` | ✗ | 无条件加 | 无害：把新版本装进 site-packages，不再尝试卸载 dist 包 |
| `setuptools<81` | ✗ | 无条件 pin | py3.7 解析不出 ≥81（setuptools 81 要求 py≥3.9），pin 自然失效 |
| polkit 预授权 | ✗（**应按目录探测**） | `test -d /etc/polkit-1/localauthority/50-local.d` → pkla；否则 `test -d /etc/polkit-1/rules.d` → JS 规则 | V20 命中 pkla，走现有逻辑 |
| DDE 会话变量 | ✗（按 `DISPLAY_SERVER`） | 已有变量：`x11` → `XDG_SESSION_TYPE=x11` + `QT_QPA_PLATFORM=dxcb;xcb`；`wayland` → 不强制 `QT_QPA_PLATFORM` | V20 桌面会话本来就有这些变量，`setdefault` 不覆盖 |
