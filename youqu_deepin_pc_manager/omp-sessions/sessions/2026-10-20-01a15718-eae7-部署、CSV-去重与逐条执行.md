
脚本行为：

| 场景 | 行为 |
|---|---|
| 非 root 执行 | 校验 `id -u`，root 直接拒绝 |
| sudo 密码错误 | 输出 `sudo 密码错误或无权限`，rc=1 |
| polkit 0.105 目录缺失 | 输出跳过，rc=0（不影响部署） |
| 规则已存在且内容一致 | 输出 `已配置, 跳过`，不重启服务 |
| 规则缺失/内容不符 | 写入 `49-pcmanager-test.pkla` → `cmp` 校验 → 重启 polkit → `pkcheck` 验证 |
| 写入或重启失败 | 明确报错，不静默成功 |

规则内容按当前执行用户生成，仅放开检测入口，修复类操作仍需鉴权：

```ini
[PCManager test authorization]
Identity=unix-user:<当前用户>
Action=org.deepin.PCManager1.doAction
ResultAny=yes
ResultInactive=yes
ResultActive=yes
```

`env.sh` 用 `||` 兜底，polkit 配置失败不会中断依赖安装。
