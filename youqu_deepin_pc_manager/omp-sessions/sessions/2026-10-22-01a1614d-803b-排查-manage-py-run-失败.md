```bash

```

项目路径仍是 `/home/uostest/youqu_deepin_pc_manager`。在 `.93` 上按不同方式执行，会看到三类不同报错：

| 执行方式 | 报错 | 根因 |
|---|---|---|
| `python3 manage.py run -a ...` | 先 `ModuleNotFoundError: No module named 'Xlib'`，随后 `NameError: name 'Xlib' is not defined` | 系统 Python 3.7 缺 `python-xlib`；`src/depends/pyautogui/__init__.py` 的 `except Xlib.error...` 又引用了未导入的 `Xlib`，把缺包错误变成了 `NameError` |
| `youqu manage.py run -a ...` | `ModuleNotFoundError: No module named 'funnylog'` | `/usr/bin/youqu` 实际是 `pipenv run python`；项目里 `Pipfile` 已被 `env.sh` 删除，pipenv 落到空的 `~/.local/share/virtualenvs/uostest-YkBaFyo2`，该 venv 只有 pip/setuptools |
| `.venv/bin/python manage.py run -a ...` | `ValueError: 当前分辨率为：1440x900,您配置的分辨率为：1920x1080, 1080x1920, 3840x1080, 1024x768` | `src/rtk/local_runner.py:137` 的分辨率守卫；VM 当前 `xrandr` 是 `1440x900`，`setting/globalconfig.ini` 的 `RESOLUTION` 不含它 |

用对解释器后，**真正拦住运行的是分辨率检查**。`.venv` 本身是完整的：103 个包，含 `funnylog`、`pytest 6.2.5`、`allure_custom`、`Xlib`、`dogtail`。

修复并执行：


```ini
RESOLUTION = 1440x900, 1920x1080, 1080x1920, 3840x1080, 1024x768
```
