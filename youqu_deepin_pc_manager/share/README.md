# .share —— 对外分享类输出

本目录存放**可脱敏后对外**的总结、方案与分享稿；原始会话证据留在 `.omp-sessions/`（过检期交互）、`.multica-sessions/`（建设期）、`.deepseek-harness-sessions/`（过检无人值守批次），三者含内部信息，不可外发。

## 规则

1. 分享稿不写测试机地址、账号/密码、内部 Git 地址、产品源码路径与行号；测试机用「测试机 A/B」代称。
2. 数据统计必须标注口径（会话数、时间范围、token 计算方式），并与仓库当前状态区分"当时数据"与"当前数据"。
3. 本目录已加入 `.gitignore`，不提交到仓库；如需归档，另行审批。
4. 文档内的会话 ID 仅用于内部定位证据，外发前按需删除。
