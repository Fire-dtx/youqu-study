# 报告归档分片说明

GitHub 单文件上限 100 MiB，超过的报告按 `zstd` 压缩后切成 90 MiB 分片入库，
文件名格式 `<原文件名>.zst.part.NN`。

| 分片前缀 | 分片数 | 原文件 | 原始大小 |
|---|---|---|---|
| `report_2026_11_17.tar.zst.part.` | 4 | `report_2026_11_17.tar` | 688 MiB |
| `report_2026_1106.tar.zst.part.` | 5 | `report_2026_1106.tar` | 650 MiB |
| `report_2026_1105.tar.zst.part.` | 4 | `report_2026_1105.tar` | 538 MiB |
| `report.zip.zst.part.` | 2 | `report.zip` | 159 MiB |

## 还原

```bash
cd 电脑管家自动化测试
# 1) 拼接分片并解压，得到原 tar/zip
cat report_2026_11_17.tar.zst.part.* | zstd -dc > report_2026_11_17.tar
cat report_2026_1106.tar.zst.part.* | zstd -dc > report_2026_1106.tar
# 2) zip 还原后可照常解压
cat report.zip.zst.part.* | zstd -dc > report.zip && unzip report.zip
```

分片必须按 `part.00` 起的字典序拼接，`cat` 通配符顺序即为字典序，可直接使用；
每个原文件的分片拼接结果已用 `cmp` 与压缩前的原文件逐字节比对一致。

未超限的 `report_2026_1102.zip`（80 MiB）、`allure_html_bak.zip`（14 MiB）保持原样。
